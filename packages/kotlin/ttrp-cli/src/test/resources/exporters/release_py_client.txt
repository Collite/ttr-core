Python client for `release_order` (`release_py`). HTTP run API,
ttr-server contracts §1 (⚑AU-EXP-3, ✅R254-A/B). Open baseline: f28120e1; action wire: #391.
The baseline has no perform route; real-Server acceptance remains P1C / #366.
Python 3.13.9; standard library runtime; pytest 8.3.5. No gRPC or proto wheel.

Set TTR_SERVER to the Server origin and TTR_BEARER to your authorized bearer.
From worker/: `uv run python -m release_order_client.main --key 4711 --as-of 2026-11-02T08:00:00Z`.
`--key` is JSON (an object for composite keys); `--batch` accepts an optional JSON keys array,
or selects all with no argument. The chosen port must match the exported program.
`--as-of` accepts `now` or an ISO instant with offset. An event program sends the literal clock in
port.at; a run-clock program needs a dry/debug run for a literal override. `--dry-run` strengthens policy.
On-event redeliveries need the same caller-supplied clock to deduplicate.
The Server owns action eligibility and execution; this package has no waits, asks or processes.
`service.py` accepts `{"requests": [...]}` on stdin and emits `{"results": [...]}` in order,
with errors per request;
`conform --replay` uses it in a subprocess with dryRun true. Replays never override parameters.
Run generated route tests: `uv run --group dev pytest`.
Re-export after any recipe text/values, program, deployment or world fingerprint change.
Only run trusted generated packages, like other executable conformance artifacts.

from __future__ import annotations
from typing import Any
from .runtime import BaseClient, BaseRun, Action

class Parts:
    def __init__(self, run: BaseRun) -> None:
        self._run = run

    def candidates(self) -> dict[str, Any]:
        return self._run.part("candidates")

    def shortfall(self) -> dict[str, Any]:
        return self._run.part("shortfall")

    def price_differences(self) -> dict[str, Any]:
        return self._run.part("price_differences")

    def overdue(self) -> dict[str, Any]:
        return self._run.part("overdue")

    def decision(self) -> dict[str, Any]:
        return self._run.part("decision")


class Routes:
    def __init__(self, run: BaseRun) -> None:
        self._run = run

    def hold_sales(self) -> list[dict[str, Any]]:
        return self._run.route("hold_sales")

    def hold_ar(self) -> list[dict[str, Any]]:
        return self._run.route("hold_ar")

    def release_confirmed(self) -> list[dict[str, Any]]:
        return self._run.route("release_confirmed")

    def release(self) -> list[dict[str, Any]]:
        return self._run.route("release")


class Actions:
    def __init__(self, run: BaseRun) -> None:
        self._run = run

    @property
    def ask(self) -> Action:
        return Action(self._run, "ask")

    @property
    def hold(self) -> Action:
        return Action(self._run, "hold")

    @property
    def notify(self) -> Action:
        return Action(self._run, "notify")

    @property
    def release(self) -> Action:
        return Action(self._run, "release")


class Run(BaseRun):
    def __init__(self, *args: Any, **kwargs: Any) -> None:
        super().__init__(*args, **kwargs)
        self.parts = Parts(self)
        self.routes = Routes(self)
        self.actions = Actions(self)


class Client(BaseClient):
    run_type = Run

    def open(self, port: dict[str, Any], as_of: str | None = None, *, dry_run: bool = False, idempotency_key: str | None = None) -> Run:
        return super().open(port, as_of, dry_run=dry_run, idempotency_key=idempotency_key)
